# Istio

Service mesh for [[OKD]]. Provides mTLS between services, traffic management, observability.

Control plane in [[overwatch-gitops]]/apps/istio-controlplane. Mesh config in apps/mesh-config. [[Jaeger]] handles distributed tracing.

Part of the [[Security Stack]] — compensating control for SC-7(5) in the [[SSP]].
