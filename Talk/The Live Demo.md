# The Live Demo

Centerpiece of [[Talk Arc]] — Section 3.

## Philosophy

Don't just show what exists. Build something live. The workflow IS the message.

"I don't know exactly what's going to happen in the next 20 minutes and that's the point."

## What to Show

### Definitely Demo-able
- [[ArgoCD]] dashboard — apps syncing live
- [[Wazuh]] dashboard — alerts, CIS scores, agent status
- [[OKD]] console — running pods, namespaces
- [[Vault]] UI — SSH cert signing
- [[Grafana Stack|Grafana]] — metrics and logs
- [[CI Pipeline]] — show a pipeline run with security scanning
- [[compliance-vault|Automated evidence collection]]
- [[Backstage]] — developer portal, catalog entities

### Live Build Candidates
- Deploy a new app via [[GitOps Pipeline]] (commit → ArgoCD sync → running pod)
- Run a compliance check and show results
- Have an [[Agent Teams|agent team]] pick up and work a [[Plane]] issue

### Backup if Network Fails
- Talk notes say: test Tailscale from conference WiFi, prepare fallback
- Could show pre-recorded demo + walk through repos locally

## The Failure Principle

"If it breaks and I catch it live, that's the whole thesis — the human is the verification layer."
